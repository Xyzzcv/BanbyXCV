# BanbyXCV

Client-side plugin for **Endcord / Vencord / Equicord**.

Membuat profil user tertentu terlihat seperti akun yang sudah di-banned dari Discord.

**Hanya berlaku di client kamu sendiri.** Discord server-side tidak terpengaruh.

## Commands

| Command | Fungsi |
|---------|--------|
| `/ban-by-xcv @user` | Tandai user sebagai banned (visual) |
| `/unban-by-xcv @user` | Hapus status banned visual |

## Install

### Manual (Recommended)

1. Masuk ke folder source Endcord/Vencord kamu
2. Buka `src/userplugins/`
3. Clone repo ini:
